5.6.1 Hạ tầng Frontend & Route 53

Mục tiêu của Lab này

Trong bài Lab này, bạn sẽ triển khai hạ tầng Serverless cho Frontend bằng AWS CloudFormation. Hệ thống bao gồm một S3 Bucket đóng vai trò làm nơi lưu trữ tĩnh (được chặn public hoàn toàn) và CloudFront (CDN) để phân phối nội dung toàn cầu. Cuối cùng, bạn sẽ dùng Route 53 để trỏ tên miền chính thức về CloudFront.

LƯU Ý CỰC KỲ QUAN TRỌNG VỀ REGION: Dịch vụ Amazon CloudFront bắt buộc chứng chỉ SSL/TLS (ACM) phải nằm ở region US East (N. Virginia) us-east-1. Để tránh lỗi không tìm thấy chứng chỉ, chúng ta sẽ thực hiện toàn bộ bài Lab Frontend này tại region us-east-1.

Các bước thực hiện

Bước 1: Khởi tạo chứng chỉ ACM tại us-east-1

  1. Nhìn lên góc trên bên phải của AWS Console, chuyển Region của bạn sang US East (N. Virginia) us-east-1.
  2. Truy cập vào dịch vụ AWS Certificate Manager (ACM) và nhấn Request a certificate.
  3. Chọn Request a public certificate và nhấn Next.
  4. Điền thông tin yêu cầu chứng chỉ chính xác như sau:
    • Fully qualified domain name: Nhập tên miền gốc của bạn (vd: minisocial-network.id.vn).
    • Validation method: Chọn DNS validation.
    • Key algorithm: Chọn RSA 2048.
  5. Nhấn Request.
  6. Khi chứng chỉ đã được cấp (Issued), hãy vào trang chi tiết và copy chuỗi ARN của chứng chỉ.

Bước 2: Lưu ARN chứng chỉ vào SSM Parameter Store

Vẫn đang ở region us-east-1, chúng ta cần lưu ARN này lại để CloudFormation có thể tự động đọc được.

  1. Truy cập AWS Systems Manager > Parameter Store.
  2. Nhấn Create parameter.
  3. Name: Nhập chính xác /minisocial/frontend/acm-certificate-arn.
  4. Type: Chọn String.
  5. Value: Dán chuỗi ARN chứng chỉ bạn vừa copy ở Bước 1.
  6. Nhấn Create parameter.

Bước 3: Chạy CloudFormation Stack cho Frontend

Tiếp theo, chúng ta sẽ tạo S3 và CloudFront.

  1. Đảm bảo bạn vẫn đang ở us-east-1. Truy cập CloudFormation > Stacks > Create stack > With new resources (standard).
  2. Chọn Upload a template file, tải lên file minisocial-frontend+cloudfront.yaml và nhấn Next.
  3. Điền các tham số cấu hình:
    • Stack name: Đặt tên là MiniSocial-Frontend-Stack.
    • FrontendDomainName: Nhập chính xác tên miền của bạn (vd: minisocial-network.id.vn).
    • Giữ nguyên đường dẫn SSM Parameter Store mặc định.
  4. Nhấn Next cho đến hết rồi chọn Submit.
  5. Chờ Stack đạt trạng thái CREATE_COMPLETE (Lưu ý: Khởi tạo CloudFront thường mất từ 5-10 phút).
  6. BƯỚC QUAN TRỌNG: Chuyển sang tab Outputs của Stack, hãy ghi chú lại 2 giá trị là FrontendBucketName và CloudFrontDistributionId. Bạn sẽ bắt buộc phải dùng 2 ID này để cấu hình file Jenkinsfile ở bài Lab kế tiếp!

Bước 4: Cấu hình Route 53 trỏ về CloudFront

Cuối cùng, chúng ta sẽ gắn tên miền vào CloudFront.

  1. Truy cập Route 53 > Hosted zones. (Route 53 là dịch vụ Global nên bạn không cần quan tâm Region ở bước này).
  2. Nhấn vào Hosted zone của bạn (đã tạo ở Phase 3).
  3. Nhấn Create record.
  4. Cấu hình bản ghi để trỏ tên miền gốc về CloudFront như sau:
    • Record name: Bỏ trống (để sử dụng tên miền gốc minisocial-network.id.vn).
    • Record type: Chọn A – Routes traffic to an IPv4 address and some AWS resources.
    • Alias: Bật công tắc sang ON.
    • Route traffic to: Chọn Alias to CloudFront distribution.
    • Value: Hệ thống sẽ tự động gợi ý CloudFront Distribution bạn vừa tạo, hãy chọn nó.
  5. Nhấn Create records.

Kiểm tra kết quả

  • Đợi khoảng 1-2 phút để DNS cập nhật.
  • Mở trình duyệt và truy cập https://minisocial-network.id.vn.
  • Nếu bạn thấy lỗi “Access Denied” hoặc màn hình trắng thì xin chúc mừng, bạn đã làm đúng! Hiện tại S3 Bucket đang trống hoàn toàn. Ở bài Lab tiếp theo, chúng ta sẽ dùng Jenkins Pipeline để Build mã nguồn React và đẩy lên lấp đầy khoảng trống này.
