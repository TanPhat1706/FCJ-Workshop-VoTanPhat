### Week 2 Objectives:

* Transition from theoretical knowledge to hands-on practice within the AWS environment.
* Successfully deploy, configure, and manage core AWS services through AWS Management Console and CLI.
* Understand the practical implementation of cloud security, networking, compute, and monitoring.

### Week 2 Achievements:

* Gained hands-on experience by completing 15 practical labs covering essential AWS domains.
* Successfully built a secure, foundational cloud infrastructure including custom networks (VPC), computing resources (EC2, Lightsail) and storage/databases (S3, RDS).
* Established proper security postures using IAM roles, policies, and Security Groups.
* Acquired the ability to manage AWS resources both through the visual Management Console and programmatically via the AWS CLI.
